# Velocity Rush — Advanced Car Racing Game

A responsive arcade-style car racing game made with **HTML, CSS and JavaScript** for a Web Technologies project.

## Features
- Canvas-based animated racing road
- Three-lane player movement
- Traffic cars with collision detection
- Increasing difficulty and levels
- Score, best score and speed display
- Boost control
- Pause, resume and restart
- Sound effects toggle
- Keyboard and mobile touch controls
- Best score saved in browser local storage
- Responsive layout

## Controls
| Action | Keyboard | Mobile |
|---|---|---|
| Move left | Left Arrow / A | Left button |
| Move right | Right Arrow / D | Right button |
| Boost | Up Arrow / Space | BOOST button |
| Pause / resume | P | PAUSE button |

## Run locally
1. Download and extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. Press **START RACE**.

No installation or external libraries are required. An internet connection is only needed to load the optional Google Fonts.

## Project structure
- `index.html` — page structure and game interface
- `style.css` — styling and responsive layout
- `script.js` — game rendering, controls, traffic, collision and scoring

## Upload to GitHub
1. Create or open your GitHub repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js` and `README.md`.
4. Enter a commit message such as `Add Velocity Rush car racing game`.
5. Select **Commit changes**.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to publish. Open the website URL shown in the Pages section.
